# COPILOT.md — Directrices para GitHub Copilot

Instrucciones de contexto para GitHub Copilot en Lilo Hub. Para la versión en `.github/`, ver [.github/copilot-instructions.md](file:///.github/copilot-instructions.md).

* **Entorno:** Python 3.12+, Docker Compose, SQLite (aiosqlite).
* **Convenciones:** Funciones asíncronas con tipado estricto, YAGNI, whitelist de seguridad en handlers.
* **Integraciones:** Telegram (`python-telegram-bot`), Google GenAI (`google-genai`), Obsidian Markdown.
